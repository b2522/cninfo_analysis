# 质押分类、回购增持摘要与分析重试设计

## 背景

公告列表只保留具备投资研判价值的机会和风险信号。现有宽泛标题候选规则会将日常“解除质押及质押”披露送入风险分类；回购进展摘要未完整输出计划信息；技术异常会使记录长期停留在“分析失败”。

## 决策

### 1. 日常解除后再质押的窄排除

当标题同时出现“解除质押”与“及质押”或“和质押”时，将“大股东减持、质押和股权变动”从候选标签中排除。若标题包含被动平仓、强制平仓、违约处置、司法冻结、轮候冻结、控制权变更或可能导致控制权变更，则不适用该排除规则。

历史记录启动修正时，符合该规则的记录改为 `dismissed`，清除既有分析字段；已是 `dismissed` 的记录不重复写入。

### 2. 回购和增持的事实摘要

以当前公告 PDF 文本为唯一事实来源。对回购进展，提取计划金额区间、回购价格上限、截至日期、累计回购股数、持股比例、成交价格区间和累计成交金额（文本存在时）。对增持公告，提取累计或计划增持股数、比例、成交均价或价格区间（文本存在时）。

摘要只写已提取到的字段；用户指定字段在原文不存在时显示“本公告未披露”，不跨公告补全，也不推测。结构化指标同步写入 `metrics`。

### 3. 技术失败的一次性重试

分析任务第一轮继续以并发数 3 执行。待所有第一轮候选完成后，仅对 PDF 下载、解析或模型调用抛出异常的记录再执行一次，重试采用串行以降低外部服务压力。第二次仍出现异常时，记录改为 `dismissed`，页面显示“已排除”；任务保持 `completed`，并在失败计数中记录最终未成功的次数。

模型正常返回但不具备有效标签或原文证据的记录属于正常排除，不进入重试。

## 验收标准

- “部分股份解除质押及质押”公告不进入机会或风险结果；高风险质押关键词仍可进入风险候选。
- 回购进展结果可包含计划金额、价格上限和当前进展；缺失字段明确标示未披露。
- 增持结果包含 PDF 可验证的比例、股数和价格事实，缺失字段不编造。
- 技术异常先重试一次，第二次失败后变为 `dismissed`；正常排除不重试。
- 既有自动化测试和新增回归测试全部通过。
