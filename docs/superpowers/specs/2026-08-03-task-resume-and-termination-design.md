# 任务恢复与终止减持分类设计

## 目标
刷新页面后仍能显示并继续轮询 SQLite 中运行的抓取、分析任务；对“提前终止减持、未减持”类公告在 PDF 正文存在对应原文时，避免因模型漏标被排除。

## 任务状态
后端提供只返回 `queued`、`running` 任务的接口。前端初始化时读取全部活动任务并继续轮询；抓取和分析并行时同时展示，且只禁用对应操作按钮。

## 分类
标题筛选继续保留高召回候选。分析完成时，如模型未给出标签，但公告标题命中“提前终止减持 / 终止减持 / 未减持”，且 PDF 正文包含同类连续原文，则确认归入机会分类“终止减持、未减持”。这保持 PDF 证据约束，同时避免模型输出不稳定造成漏报。

## 历史修复
将已被排除且标题命中该正向模式的公告恢复为待分析，以便用户下一次点击分析时按新规则处理；不影响其他已确认结论。
