# 分析任务反馈与界面极简改版设计

**日期：** 2026-08-03

## 目标

改善“开始分析”后的可感知反馈，并将现有本地公告研判页面重构为深色数据终端搭配浅色结果卡片的简洁工作台。

## 范围

- 只修改静态 HTML、CSS、JavaScript 与静态页面测试。
- 不修改 FastAPI API、巨潮抓取、PDF 解析、模型调用、MongoDB 存储与任务状态协议。
- 不增加第三方前端依赖或远程视觉资源。
- 不新增结果标签页计数；当前接口没有为所有视图提供统一计数，避免引入额外请求和多标签重复计数口径。

## 任务状态与反馈契约

### 既有接口字段

创建请求使用 `POST /api/tasks`，成功响应仅以 `task.id` 建立轮询。后续仅使用既有字段：`task.status`、`task.processed`、`task.candidates`、`task.failures`。不读取或新增 `task.stage`、总量或进度百分比。

状态显示映射固定为：

- `queued` → `排队中`
- `running` → `分析中`
- `completed` → `已完成`
- `failed` → `分析失败`

任务信息条显示中文状态及“已处理 N · 候选 N · 失败 N”。没有总量字段，因此仅使用不确定型细条动画，终态后停止动画；不展示虚假的百分比。

### 开始分析按钮

1. 点击时立即锁定，设置 `disabled` 和忙碌文案 `正在创建任务…`，从而阻止重复 POST。
2. 创建请求成功后，按钮保持锁定并显示 `后台分析中`，直到该任务进入 `completed` 或 `failed`。
3. 创建请求失败、网络异常或轮询确认任务不存在时，恢复为可点击的 `开始分析`。
4. 终态后恢复为可点击的 `开始分析`。

### Toast

页面包含唯一的 Toast 容器，使用 `role="status"` 和 `aria-live="polite"`。单条 Toast 默认 4 秒后自动消失，并以 `textContent` 写入内容。

固定反馈：

- 创建成功：`任务已创建，正在后台分析`
- 创建失败或网络异常：`任务创建失败：<原因>`
- 任务完成：`分析完成，结果已更新`
- 任务失败：`任务分析失败，请检查任务状态`
- 轮询失败：`暂时无法获取任务进度，将自动重试`

终态提示按 `任务 ID + status` 去重，每个任务每种终态只展示一次。轮询的 HTTP 404 明确表示任务不存在：停止轮询、清除当前任务 ID、恢复“开始分析”按钮，并提示“任务不存在，请重新开始分析”。网络异常和其他非 2xx 响应属于可恢复错误：保留当前任务与按钮锁定状态，至多提示一次“暂时无法获取任务进度，将自动重试”，并在 2.5 秒后继续轮询。非 JSON 错误响应以 HTTP 状态或通用错误文案呈现。

任务完成后刷新当前结果视图。所有状态均以 Toast 和任务信息条呈现，不使用浏览器原生 `alert()`。

## 视觉设计与可验收参数

### 布局

- `body` 使用深灰蓝背景 `#101827`；页面最大宽度保持 `1160px`。
- 顶部信息区与控制区使用深色面板 `#172236`，圆角 `22px`，间距 `24px`。
- 控制区顺序固定为：日期快捷键 → 起止日期 → 主操作按钮；桌面端同一行、窄屏端自动换行。
- 任务信息条置于控制区下方、结果分组导航上方，始终显示；默认文本为“尚未启动分析”。
- 结果列表背景转为低对比浅灰 `#f4f6f8`，单张结果卡片为白色，圆角 `16px`。

### 色彩与层级

- 文字主色 `#142033`，次级文字 `#64748b`，强调色 `#4f8cff`。
- 机会标签：青绿背景/文字；中性：石板灰背景/文字；风险：朱红背景/文字。
- 分组导航使用活动下划线和强调色，不增加没有可靠数据源的计数。
- 主要按钮的正常、悬停、禁用状态均有可见区别；禁用态不显示为可点击。

### 响应式

保留并以 `700px` 为断点。`≤700px` 时：顶部栏、控制区、结果卡片标题区改为单列；主按钮宽度拉伸至可用宽度；任务信息条允许内容换行。

## 验收标准

1. 静态测试确认存在 Toast 容器、`aria-live`、任务状态中文映射和 `正在创建任务…`。
2. 静态测试确认不包含 `alert(`，并保持 `row.result_views` 分组渲染与 DOM API / `textContent` 安全渲染方式。
3. 静态测试确认按钮禁用逻辑、创建成功的 Toast、终态去重标记及 `completed` 后结果刷新代码存在。
4. 浏览器烟雾测试：点击开始分析后即时显示忙碌状态；创建成功后任务信息条显示“排队中”或“分析中”；切换结果标签仍有效。
5. 浏览器烟雾测试：桌面页面具备深色顶部工作区、白色结果卡片；在 700px 以下无横向溢出。
