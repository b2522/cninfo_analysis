# 出售回购股份风险归类与回购摘要扩展设计

**日期：** 2026-08-03

## 目标

将“出售已回购股份 / 出售回购股份”视为风险信号，并统一“股份回购 / 回购公司股份”等公告的原文事实摘要顺序。

## 归类规则

- 标题命中“出售已回购股份”或“出售回购股份”时，进入“**大股东减持、质押和股权变动**”风险候选。
- 只有 PDF 原文存在相应出售事实时才确认风险；标题筛选本身不直接给出最终结果。
- 结果摘要明确注明“出售已回购股份（相当于减持）”，并保留原文证据。

## 回购摘要规则

适用于标题包含“股份回购”或“回购公司股份”的公告，按固定次序输出：

1. 回购计划：资金总额（范围或单一金额）、回购价格上限；
2. 回购进展：截至日期、累计回购股份与比例、累计回购总金额、最高成交价、最低成交价。

每一项只从当前 PDF 提取。当前 PDF 未披露时写“本公告未披露”，不引用历史公告、不推测。

## 历史数据

已确认但摘要仍是旧格式的上述回购公告，将重新置为候选一次；新格式摘要与不相关公告不受影响。

## 验收

- 出售已回购股份公告经 PDF 证据确认后显示为风险。
- 回购公告摘要按“计划→进展”顺序，覆盖资金总额、价格上限、累计金额、最高价、最低价。
- 未披露字段明确标注。
- 单元测试、编译检查和本地服务健康检查通过。
